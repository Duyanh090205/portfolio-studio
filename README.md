# Portfolio Studio: a marketing team of Claudes

A Claude plugin for building **fictional-brand portfolio work**. Each "team member" is one skill. The members hand work to each other through files in a local folder, and a visual **HUB.html** page tracks everything.

| # | Member (skill) | Makes |
|---|---|---|
| 0 | Brief (`new-brand`) | Strategic brief from a short interview |
| 1 | Brand Strategist | 3 directions → brand kit, 5 SVG logos, palette, type, brand board, 8 photo prompts |
| 2 | Social Media Creative | 3 content pillars, 4 posts + 1 story, captions & hashtags |
| 3 | Campaign Designer | 3 concepts → campaign platform, portrait key visual + 16:9 banner |
| 4 | Packaging Designer | Pack front, seal/sticker, thank-you card, pack copy, mockup prompts |
| 5 | OOH Designer | Billboard + poster, placement plan, in-context mockup prompts |
| 6 | Proposal Designer | Case-study deck (PDF-ready) + portfolio page copy |
| + | Video Editor | Storyboard + 1080x1920 GSAP motion ad |
| + | Ads Manager | Competitive ads analysis report + 3 ad concepts with Meta copy |
| + | Report Analyst | Monthly report: simulated (portfolio), measurement plan, survey data, creator analytics, or real exports |
| + | Content Planner | Real brands: monthly calendar, weekly Reels scripts + shot lists, caption batches |
| ✓ | Import project / Project check | Bring existing projects in (reads your PDFs, pages, screenshots); QA before publishing |

**Project types:** `fictional` (new portfolio brand) · `concept` (your own concept brand, identity imported) · `real-brand` (unsolicited campaign for a real company: official logo files only, disclaimer everywhere) · `cause` (PSA / social issue) · `content` (creator channel) · `live` (a real business you run: real photos, compliance checks, monthly content planning). Each type switches steps on/off and changes defaults.

Visuals are HTML built on a tested layout kit (`_system/layouts.css`), so brand fonts, colours and copy are exact. Photos are generated by the user in Gemini or ChatGPT from prompts the HUB lets them copy, and the HUB drops them in automatically.

## For the user

👉 **Vietnamese step-by-step guide: [HUONG-DAN.md](HUONG-DAN.md)**, covering install, daily use, exports and troubleshooting.

In short: install the Claude Desktop app → **Customize → Plugins → Add marketplace → `Duyanh090205/portfolio-studio`** (or in Claude Code: `/plugin marketplace add Duyanh090205/portfolio-studio` then `/plugin install marketing-team@portfolio-studio`) → open the **Code** tab on an empty folder → type **"Setup Portfolio Studio"**. Open **HUB.html**. A sample brand (CEMMY) shows what each member produces.

## For the developer

```
.claude-plugin/marketplace.json        marketplace listing (this repo)
plugins/marketing-team/
  .claude-plugin/plugin.json
  shared/conventions.md                rules every skill follows (pipeline, modes, step.js, honesty, token discipline)
  shared/data-schema.md                brand.js / kit / logos / brand.css schema (studio, new-brand, brand-strategist only)
  shared/html-guide.md                 layout kit + HTML rules (roles 2–9)
  skills/<skill>/SKILL.md              one skill per team member
  skills/<skill>/references/           synced copies of shared/ (by tools/sync_shared.py)
  skills/studio/assets/workspace/      HUB.html + _system/ (app.js, app.css, compose.js, layouts.css, VERSION) + sample brand
tools/sync_shared.py                   sync shared/ into skills
tools/build.py                         sync + LF-normalise + build dist/marketing-team.zip and dist/portfolio-studio-starter.zip
```

- **Edit the conventions only in `shared/`,** then run `python tools/sync_shared.py`. Skills must be self-contained, so each one gets its own copy.
- **Every release:** bump `plugin.json` → `version` (marketplace updates key off it). When the HUB changes, also bump `_system/VERSION` and `VERSION` in `app.js`; the `studio` skill refreshes an outdated HUB in the user's folder. Run `python tools/build.py`, then attach both zips from `dist/` to a GitHub Release.
- **Validate:** `claude plugin validate .` and `claude plugin validate plugins/marketing-team`.
- **To test locally without publishing:**
  `claude -p "Setup Portfolio Studio" --plugin-dir plugins/marketing-team`
  Run it from an empty folder outside this repo, so this repo's CLAUDE.md doesn't leak into the test.
- **Data files** (`brand.js`, `logos.js`, `portfolio.js`) are loaded with `<script>` tags. That lets the HUB run from `file://` with no server.
